# Toma — сайт приложения

Сайт виртуального питомца Toma (полосатый котёнок на рабочем столе).

- Сайт: https://takomak2012-cyber.github.io/Toma/
- Приложение в RuStore: https://www.rustore.ru/catalog/app/com.tomagochi.pet
- Политика конфиденциальности: https://takomak2012-cyber.github.io/Toma/privacy.html

## Структура

```
index.html            главная страница
privacy.html          политика конфиденциальности
assets/style.css      стили (тёмно-синяя тема приложения)
assets/icon-512.svg   иконка приложения
app-ads.txt           файл для рекламной сети Яндекса (РСЯ)
ads.txt               файл для рекламной сети Яндекса (РСЯ)
```

Сайт статический, внешних зависимостей нет, публикуется через GitHub Pages из корня ветки `main`.

## Файлы для рекламной сети Яндекса (РСЯ)

`app-ads.txt` и `ads.txt` публикуются как есть, без правок. Файлы кладутся в корень
сайта, адрес проверяется по типу `.../Toma/app-ads.txt`.

## Как обновить

1. Изменить файлы в этом репозитории.
2. Закоммитить и запушить в `main`.
3. GitHub Pages опубликует изменения автоматически.
